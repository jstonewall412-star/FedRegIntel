Original videos. Creator-reviewed drafts.

Development status: a desktop prototype for sandbox testing. TikTok production approval and a verified end-to-end demonstration are pending. This page does not accept credentials or videos.

FedReg Intel explains federal rulemaking and public-comment opportunities through original educational videos. The owner-run desktop uploader sends a selected local video to the authorized TikTok account as a draft. The creator finishes the caption, AI-generated-content label, own-brand disclosure, visibility, and publishing decision inside TikTok.

How it works

  1. Run the desktop app on the owner's computer.
  2. Load the app's sandbox credentials locally, then connect with TikTok.
  3. Confirm the connected profile and preview an original MP4.
  4. Resolve fact-check issues and verify the paired YouTube episode is public and playable.
  5. Explicitly approve sending this video as a draft.
  6. Check processing status, then review and post through the TikTok inbox notification.

Scope and limits

Uses Login Kit and Content Posting API with user.info.basic and video.upload. It does not request video.publish, publish unattended posts, or copy arbitrary creators' content. The starter accepts MP4 files up to 64 MiB and holds ambiguous upload attempts for status checks.

Both FedReg Intel and Ministry of Petty presently use @jstonewall412. Separate developer organizations do not create separate TikTok posting accounts. Verify the profile before each upload.
